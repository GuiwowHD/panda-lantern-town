# 课程内容与词汇表

[English](./curriculum.en.md) | 简体中文

本文完整列出 Panda Lantern Town 的教学内容：单元结构、24 个核心词汇、
16 个声调练习、12 组句子练习，以及计分与解锁规则。数据来源为 `src/data.ts`，
如代码与此文档不一致，以代码为准。

## 教学设计

- **听力优先**：三个挑战都以「先听」开始，不要求孩子认读汉字；汉字与拼音始终作为辅助信息出现。
- **声调意识**：每个单元安排 4 个声调练习，用音高曲线图（高平 / 上升 / 降升 / 下降）
  帮助孩子把「声音的形状」和普通话四声对应起来。
- **小步快跑**：每关 3–6 轮、1–2 分钟即可完成，答错不扣分、可立即重试，保持低挫败感。
- **句型模板**：12 个句子全部由简单模板生成（我要 / 我想 / 我喜欢 / 是 / 爱 / 会），
  词块搭配量词（一个 / 一只 / 一条），让孩子自然吸收基本语序。

## 挑战规则与计分

### 灯笼市场（听词选图）

- 每单元 6 轮 = 6 个词汇；每轮播放一个词，从 3 张图片中选择；
- 选项在轮与轮之间轮换位置，避免「总点同一个位置」；
- 答错不结束本轮：提示重试，本轮最终只得 1 分。

### 声调滑梯（辨四声）

- 每单元 4 轮，出场顺序随机；
- 每轮播放一个音节，从 4 张声调卡片（附音高走向曲线）中选择；
- 答对后展示拼音与声调描述，强化「声音形状」的记忆。

### 句子小桥（拼句子）

- 每单元 3 轮；按顺序点击词块填入句子槽位；
- 填满后自动判定；错误时清空重拼，本轮最终只得 1 分；
- 英文提示默认显示，可一键隐藏以提高难度。

### 计分与星级

| 规则 | 数值 |
|------|------|
| 首次答对 | +2 分 |
| 答错后答对 | +1 分 |
| 灯笼市场满分 | 6 轮 × 2 = 12 分 |
| 声调滑梯满分 | 4 轮 × 2 = 8 分 |
| 句子小桥满分 | 3 轮 × 2 = 6 分 |
| ★★★ | 得分率 ≥ 90% |
| ★★ | 得分率 ≥ 65% |
| ★ | 完成即获得 |

星级取历史最佳，可随时重玩刷新。全游戏共 4 单元 × 3 挑战 × 3 星 = **36 颗星**。

## 家长面板（Grown-ups）

- 显示每个单元、每个挑战的最佳星级与解锁状态，总计 36 星；
- 「Pinyin helpers」开关：关闭后单元词汇条与词块只显示英文，隐藏拼音；
- 「Reset all progress」：确认后清空全部进度；
- 页面明确标注：无账号、无广告、无远程档案，进度只保存在本浏览器。
